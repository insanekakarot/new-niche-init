All rule prompts run in the same project conversation, so each one sees the script and the earlier answers.

In the TSV

Rule Prompts column
VALIDATION = """ Check the script …
Use exactly one of: STATUS - APPROVED
or STATUS - NOT APPROVED """

REVISION = """ Apply all suggested fixes …
Narration: {{ '{{' }} words_range {{ '}}' }} words.
Output the script in a code block. """
Rules column
> audits
LOOP (MAX 5) {
    VALIDATION;
    IF (TAG == "APPROVED") { BREAK; }
    REVISION;
}

One line or many: line breaks and spaces don't matter.

Good to know

  • • MAX counts passes. One pass = the check, plus a fix if needed. With LOOP (MAX 3) the 3rd fix is never checked; use MAX 4 with ELSE IF (ITERATION == 4) { STOP; } to check every fix.
  • • REVALIDATE ends the pass; the next pass starts with the check again.
  • • TAG is compared exactly. If a rule says TAG == "TRUE", the check prompt must ask for that word in its status line. The upload warns you when no check prompt does.
  • • Every name you run must be declared in Rule Prompts, or the upload stops with an error.
  • • After uploading, the Dashboard shows each brand's rules line by line, with a sample run.
